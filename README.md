# trading-lab

Честна лаборатория за backtest. Целта е бързо и евтино да **опровергаем** лошите идеи, преди да струват пари.

## Принципи (вградени в кода)
- **Без поглед в бъдещето.** Стратегията вижда само `History` до момента на решението; опит да прочете следващ бар хвърля `LookAheadError`.
- **Закъснение (`lag`).** Решение в края на бар *t* печели от бар *t+1+lag*. За месечни средни цени (Shiller) е задължително `lag: 1`.
- **Разходи винаги.** `cost` = част от търгуваната сума при всяка промяна на теглото.
- **Лоши данни = грешка, не тиха грешка.** Липсващи дивиденти, дупки в дневните данни, неподредени дати → `DataError`.
- **Две независими реализации.** `scripts/golden_python.py` (Python) и TypeScript engine-ът трябва да дават едни и същи числа.

## Използване
```bash
npm install
npm run data       # изтегля S&P 500 (Shiller) и BTC/ETH (CoinMetrics) в ./data
npm run check      # type-check + всички тестове
npm run report     # калибриране спрямо публикувания резултат на Faber
```

## Какво проверяват тестовете
| Файл | Какво |
| --- | --- |
| `metrics.test.ts` | CAGR, волатилност, Sharpe, max drawdown — срещу ръчно сметнати примери |
| `engine.test.ts` | Кога решението започва да печели (lag), разходи при вход/изход, защити |
| `lookahead.test.ts` | Стратегия, която „надниква“, се спира; промяна на бъдещите данни не променя миналите решения |
| `strategies.test.ts` | SMA trend и volatility targeting — срещу независимо изчисление |
| `data.test.ts` | Зареждане на данните и отказ при лоши данни |
| `golden.test.ts` | Съвпадение с Python реализацията (8 случая) + калибриране спрямо Faber (S&P 500, 1901–2012) |

Проверено и чрез умишлено вкарани грешки (поглед с 1 бар напред; игнорирани разходи) — тестовете ги хващат.

## Резултат от калибрирането (S&P 500, 1901–2012, без разходи)
| | Този engine | Faber (публикувано) |
| --- | --- | --- |
| Buy-and-hold, % год. | 9.42 | 9.3 |
| 10-месечна SMA, % год. | 10.22 | 10.2 |
| Max drawdown buy-and-hold | −81.8% | −83.5% |
| Max drawdown SMA | −46.7% | −50.3% |

Разликите идват от данните: Shiller дава месечни средни цени, Faber — цени в края на месеца; кешът тук е 10-годишната доходност (оптимистично), при Faber — краткосрочни ДЦК.
